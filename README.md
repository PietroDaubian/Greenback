# Greenback

App de controle financeiro pessoal (receitas, despesas, fatura do cartão e calendário de contas).

Sem configurar o Firebase (arquivo firebase-config.js), os dados ficam só no aparelho.
Com o Firebase configurado, o app pede login e sincroniza os dados de cada conta online.
As regras de segurança do banco estão em firestore.rules.
